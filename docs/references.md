## External background paper

Rifky Kurniawan et al. “Electric Bionic Legs Used Gyroscope And Accelerometer With Fuzzy Method.” 2019 International Symposium on Electronics and Smart Devices (ISESD). DOI: [10.1109/ISESD.2019.8909541](https://doi.org/10.1109/ISESD.2019.8909541).

This is a different team's research. It discusses a fuzzy-control approach using inertial sensing and load cells. It is included here as a bibliographic reference, not evidence that this project implemented the same controller. The supplied third-party PDF is not redistributed in this package.
